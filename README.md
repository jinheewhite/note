# 판서노트

전자칠판에서 PDF 수업 자료를 열고, 그 위에 필기하고, **날짜별로 자동 저장**하는 웹 앱입니다.

**파일 하나(`index.html`)가 프로그램 전부입니다.** 설치도, 회원가입도, 인터넷 연결도 필요 없습니다.
USB에 담아 전자칠판에 꽂고 더블클릭하면 바로 열립니다.

👉 인터넷이 되는 교실이라면: `https://<아이디>.github.io/panseo-note/`

---

## 무엇을 할 수 있나요

| 기능 | 설명 |
|---|---|
| PDF 열기 | 수업 자료 PDF를 화면에 띄웁니다 |
| 필기 | 펜 4색 · 형광펜 · 지우개 · 되돌리기 (`Ctrl+Z`) |
| 날짜별 자동 저장 | 손을 떼면 자동 저장. 다음 날 같은 PDF를 열면 **빈 화면**에서 시작하고, 날짜를 바꾸면 지난 판서가 그대로 나옵니다 |
| 쪽 표시 | 왼쪽 목록에서 그날 판서한 쪽에 노란 점이 붙습니다 |
| 이 쪽 저장 | 현재 화면을 PNG 그림으로 내려받기 |
| 오늘 수업 PDF로 저장 | 판서한 쪽만 모아 한 개의 PDF로 내려받기 (학생 배포용) |
| 백업 / 복원 | ⚙︎ 버튼 → 판서 전체를 JSON 파일로 받아 두고, 다른 컴퓨터에서 되살릴 수 있습니다 |

쪽 넘기기는 `←` `→` 키나 블루투스 리모컨으로도 됩니다.

## 정보 담당 선생님께 (보안 확인용)

- **외부로 나가는 통신이 없습니다.** 필요한 라이브러리(PDF.js, jsPDF), 한글 글자표(CMap), 기본 글꼴까지 전부 `index.html` 안에 들어 있습니다. 실행 중 어떤 서버에도 접속하지 않습니다.
- 확인 방법: 브라우저에서 `F12` → `네트워크` 탭을 켠 채 앱을 쓰면 **요청이 0건**입니다. 랜선을 뽑고 써 보셔도 동일하게 동작합니다.
- **PDF도 필기도 그 컴퓨터 밖으로 나가지 않습니다.** 업로드·로그인·사용자 추적 코드가 없습니다.
- 사용한 라이브러리는 모두 오픈소스입니다. PDF.js(Apache-2.0, Mozilla), jsPDF(MIT).
- `build/` 폴더에 원본 코드와 빌드 스크립트가 있어, 배포된 `index.html`이 그 코드에서 나온 것임을 직접 확인·재생성할 수 있습니다.

## 저장 방식 세 가지

앱 오른쪽 위 ⚙︎ 버튼을 누르면 지금 어떤 방식으로 저장 중인지 표시됩니다.

| 표시 | 언제 | 무엇이 저장되나 |
|---|---|---|
| **정상** | 인터넷 주소(`https://…`)로 열었을 때 | 필기 + PDF 원본까지 보관. 최근 파일에서 바로 다시 열림 |
| **간이 저장** | `index.html` 파일을 직접 더블클릭했을 때 | 필기는 저장되지만 PDF 원본은 보관하지 않아, 매번 파일을 다시 선택 |
| **저장 안 됨** | 브라우저가 저장을 막는 환경 | 창을 닫으면 사라짐. 수업 끝에 반드시 PDF로 내려받기 |

USB로 쓰실 때는 대부분 **간이 저장**으로 동작합니다. 필기가 남으므로 수업에는 문제가 없지만,
학기 중 한 번씩 ⚙︎ → `판서 전체 백업 받기`를 눌러 두시길 권합니다.

기억해 두실 점:
- 저장 위치가 **기기별·브라우저별**입니다. 교실 전자칠판의 판서는 교무실 PC에 없습니다.
- 브라우저 인터넷 사용 기록·사이트 데이터를 지우면 판서도 함께 지워집니다.
- 여러 선생님이 한 전자칠판을 쓰면 판서가 한곳에 쌓입니다.
- 교과서·문제집 PDF는 저작물입니다. **이 저장소에 올리지 마세요.** 앱만 공유하고 자료는 각자 컴퓨터에서 엽니다.

## 전자칠판에 설치하는 법

**방법 1 — USB (인터넷 없이)**
1. `index.html` 을 내려받아 USB에 담습니다. 이름은 `판서노트.html` 처럼 바꿔도 됩니다.
2. 전자칠판 바탕화면에 복사하고 더블클릭합니다. Chrome이나 Edge로 열립니다.

**방법 2 — GitHub Pages (주소로 공유)**
1. 이 저장소를 본인 계정으로 만들거나 Fork 합니다.
2. `Settings` → `Pages` → Source를 `Deploy from a branch`, 브랜치 `main` / `/ (root)`.
3. 1~2분 뒤 `https://<아이디>.github.io/panseo-note/` 로 열립니다. 주소만 보내면 끝입니다.

## 직접 빌드하려면

```bash
npm pack pdfjs-dist@3.11.174 jspdf@2.5.1
tar xzf pdfjs-dist-3.11.174.tgz
tar xzf jspdf-2.5.1.tgz --one-top-level=jspdf
python3 build/build.py        # → index.html 생성
```

`build/app.template.html` 이 사람이 읽는 원본이고, `build/build.py` 가 라이브러리를 그 안에 끼워 넣습니다.

## 만든 이유

수학 수업에서 PDF를 띄우고 판서하다 보면 수업이 끝나는 순간 그 판서가 사라집니다.
결석한 학생에게 보내주거나 다음 시간에 이어서 설명하려면 매번 다시 그려야 했습니다.
그래서 "열고 · 쓰고 · 날짜별로 남는" 것만 하는 앱을 만들었습니다.
