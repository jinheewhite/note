판서노트 설치 안내
=====================================
전자칠판용 PDF 필기 프로그램입니다.


[ A. 안드로이드 전자칠판에서 쓸 때 ]  ** 이 방법을 권합니다 **

  안드로이드는 USB 안의 파일을 브라우저로 여는 것이 잘 되지 않습니다.
  아래 주소로 접속하는 방식이 확실합니다.

  1. 전자칠판의 크롬 브라우저를 엽니다.
  2. 주소창에 다음을 입력합니다.

       jinheewhite.github.io/note

  3. 오른쪽 위 점 세 개 메뉴를 누릅니다.
  4. "홈 화면에 추가" 또는 "앱 설치"를 누릅니다.
  5. 홈 화면에 판서노트 아이콘이 생깁니다. 끝입니다.

  * 한 번 접속해 두면 인터넷이 끊겨도 열립니다.
  * 이 방법은 PDF 원본까지 기억해서, 최근 파일에서 바로 다시 열립니다.


[ B. 연결된 윈도우 PC에서 쓸 때 ]

  1. USB를 꽂습니다.
  2. 설치.bat 을 두 번 누릅니다.
     - 파란 보안 경고가 뜨면 "추가 정보" - "실행"
  3. 검은 창이 끝나면 아무 키나 누릅니다.
  4. 바탕화면에 판서노트 아이콘이 생깁니다. USB는 빼셔도 됩니다.

  * 인터넷 없이 설치되고 실행됩니다.
  * 이 방법은 필기는 날짜별로 저장되지만,
    PDF는 열 때마다 다시 선택해야 합니다.
    (브라우저가 파일에서 직접 연 페이지에는 저장 공간을 적게 주기 때문입니다)


[ 사용 방법 ]

  1. 아이콘을 두 번 누릅니다.
  2. "PDF 열기"로 수업 자료를 고릅니다.
  3. 펜으로 필기합니다.
     - 손바닥으로 밀면 화면이 움직입니다
     - 두 번 톡톡 치거나 오른쪽 아래 + 버튼으로 확대합니다
     - 레이저 버튼은 쓰면 1.5초 뒤 저절로 사라집니다
  4. 수업이 끝나면 "오늘 수업 PDF로 저장"을 누릅니다.


[ 꼭 알아두실 점 ]

  - 원본 PDF는 절대 바뀌지 않습니다. 읽기만 합니다.
  - 필기는 그 기기 안에만 저장되며 어디로도 전송되지 않습니다.
  - 그래서 전자칠판에서 한 필기는 교무실 PC에서 보이지 않습니다.
  - 브라우저 사용 기록을 지우면 필기도 함께 지워집니다.
    설정(톱니바퀴) 버튼에서 가끔 백업을 받아 두세요.


[ 삭제 ]

  삭제.bat 을 두 번 누르면 아이콘과 프로그램이 지워집니다.
