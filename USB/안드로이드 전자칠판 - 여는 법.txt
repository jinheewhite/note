판서노트 — 안드로이드 전자칠판에서 여는 법
========================================================
25.8


■ 먼저 알아두실 것

  안드로이드용 "설치 파일" 은 없습니다.
  만들지 않은 것이 아니라, 있을 수가 없습니다.

  판서노트는 앱이 아니라 웹 페이지입니다. 그래서 apk 같은 설치 파일이
  아니라 크롬으로 여는 방식입니다. 안드로이드에서 "설치" 는 파일을
  실행하는 일이 아니라, 크롬 메뉴 안에서 하는 일입니다.

  이 USB 의 "윈도우용" 폴더는 이름 그대로 윈도우 컴퓨터용입니다.
  안드로이드에서 그 안의 설치.bat 을 누르면 "실행 파일 종류" 같은
  말만 나오고 아무 일도 일어나지 않습니다. 열지 마세요.


  ────────────────────────────────────────────────────
  방법 1   인터넷이 한 번이라도 되면   ← 이 방법을 권합니다
  ────────────────────────────────────────────────────

    한 번만 연결하면 됩니다. 그 뒤로는 인터넷을 꺼도 열립니다.
    홈 화면에 아이콘도 생기고, USB 도 필요 없어집니다.

      1) 크롬을 열고 아래 주소로 들어갑니다.

             jinheewhite.github.io/note

      2) 오른쪽 위 톱니바퀴(설정) 를 누릅니다.
      3) "앱으로 설치하기" 를 누릅니다.
      4) 홈 화면에 판서노트 아이콘이 생깁니다.

    "앱으로 설치하기" 가 보이지 않으면
      크롬 메뉴(점 세 개) → "홈 화면에 추가" 를 눌러 주세요.
      같은 결과입니다.

    ※ 안드로이드 8 이어도 됩니다. 크롬만 최근 판이면 되고,
       안드로이드 판 번호는 상관없습니다.


  ────────────────────────────────────────────────────
  방법 2   인터넷이 전혀 없을 때   (USB 에서 바로)
  ────────────────────────────────────────────────────

    설치는 되지 않습니다. 열어서 쓰는 것만 됩니다.
    자료와 필기는 전자칠판 안에 저장되므로 쓰는 데에는 문제가 없습니다.

      1) USB 를 전자칠판에 꽂습니다.
      2) 전자칠판의 "파일 관리자" 를 엽니다.
      3) USB 안의  판서노트.html  을 손가락으로 길게 누릅니다.
      4) "연결 프로그램" 또는 "다른 앱으로 열기" 를 고릅니다.
      5) 목록에서 Chrome 을 고릅니다.

    ● 목록에 Chrome 이 없을 때
        파일을 전자칠판 내부 저장소(내장 메모리)로 먼저 복사한 뒤
        다시 해 보세요. USB 에서 여는 것을 막는 기기가 있습니다.

    ● 그래도 안 될 때
        크롬 주소창에 직접 쳐 보세요.
        (파일을 다운로드 폴더에 복사해 둔 경우입니다)

            file:///storage/emulated/0/Download/panseo-note.html

    ● 한글 이름 때문에 안 열릴 때
        같은 폴더의  panseo-note.html  을 대신 여세요.
        내용이 똑같은 파일입니다.

    ● 열고 나서 홈 화면에 두고 싶으면
        크롬 메뉴(점 세 개) → "홈 화면에 추가"
        아이콘이 생깁니다. 다만 이것은 그 파일을 여는 바로가기이므로,
        파일을 내부 저장소에 복사해 두셔야 USB 없이 열립니다.


■ 안드로이드 8 에서 있었던 일

    자료를 열다가 화면이 꺼지는 일이 있었습니다. 고쳤습니다.
    그림을 그리는 데 쓰는 메모리를 여섯 배 줄였습니다.

    혹시 그래도 꺼지면 그냥 다시 열어 주세요. 지난번에 꺼진 것을
    앱이 알아채고 더 가볍게 엽니다. 수업 중에 손쓸 수 없게 되는
    일은 없도록 해 두었습니다.

■ 새 판으로 바꾸기
